# 情绪判定实验报告（2026-11-06）

> **修订（2026-11-06 晚）**：本报告第二节有两处已修正，详见 `REPORT_TIERS.md`
>
> 1. **HNR 口径错误**：原实现把 harmonicity 在整条音频上取中位，静音帧（Praat 返回 `-200`）
>    占多数时整块塌成哨兵值 ⇒ 量的是静音占比，不是气声。48 条里 10 条误报，
>    真人中性锚点也从 6.2dB 修正为 **13.5dB**。修正后生成侧中位 13.8dB、最低 9.9dB，
>    **「气声/发虚」相关结论全部作废**。
> 2. **「happy 做不出来」过头了**：去掉 V 权重后 happy 命中 5 条，`E_scold+angry`
>    跨度 126（目标 153）、A 0.58（目标 0.59）都对，**只有 V 差 0.34**。
>    正确表述是「跨度和强度做得到，只有 V 做不到」，而 V 做不到导致 happy≈afraid、sad≈calm 不可分。

## 一、这轮到底测了什么

**48 条生成**：8 个角色音色档（两主角各 4 档）× 6 个条件（无标签 + 5 个 emo 标签）。
同一句台词、同一 seed(2051)、同一组解码参数（`steps=8 / max_tokens=280 / xvector=on`），
唯一变量就是标签 ⇒ **差值可以干净地归因给标签**。

**三通道打分**（同一批音频全部跑齐 48/48）：
- `vox_dim`：Vox-Profile 的 MSP-Podcast 维度头 → arousal / valence / dominance
- `e2v`：emotion2vec+ large（阿里 FunASR，2024 社区离散分类标杆）→ 9 类概率
- `phys`：Praat 物理量 → F0 中位 / **F0 跨度(p90-p10)** / 语音段 dBFS / HNR

**真人校准基准**：Expresso 745 条带 style 标注的真人口语，同三个通道全部跑过一遍。
所有效应量都除以**真人合并组内 SD**（A=0.0729 / V=0.1301 / D=0.0659）换算成 σ，
不设拍脑袋的绝对阈值。

## 二、五条硬结论

### 1. 标签只能「往回收」，不能「往外扩」

40 个 (ref × 标签) 配对里，**22 个方向正确且有量，18 个方向错误**。规律不是随机的：

| ref 的 base arousal | 打标签后 ΔA |
|---|---|
| 低（C_soft −5.73σ / E_calm −3.91σ / C_normal −2.49σ） | **全部 +1.4 ~ +7.0σ**（往上顶） |
| 高（C_excited +5.16σ / C_angry +3.86σ / E_loud +3.68σ） | **大多 −0.4 ~ −2.0σ**（往回收） |

相关系数 `r(base_A, ΔA) = −0.642`，斜率 −0.394。
⇒ **标签的实际作用是「把表达强度拉向中间」，不是「设定成某个情绪」。**

### 2. 能用的只有 arousal 类标签，sad / calm 基本作废

14/40 组合通过判定，按情绪看：

| 标签 | 通过 | 说明 |
|---|---|---|
| happy | 3/8 | C_normal +1.79σ（跨度 56→106Hz，音量只 +0.7dB）干净 |
| angry | 3/8 | C_normal +4.84σ，但跨度到 185Hz、音量 +5.3dB，已在「吼」的边缘 |
| sad | **1/8** | 只有 E_scold −1.35σ；在低 A ref 上全部反向（C_normal +0.27、E_calm +5.16） |
| afraid | **1/8** | 只有 E_calm +1.82σ |
| calm | **1/8** | 只有 E_scold −2.47σ；其余 7 个全反向 |

**低 arousal 情绪（sad / calm）没法靠标签做出来** —— 标签的机制是加能量，
而降能量它做不到。要「难过 / 平静」只能靠 ref 本身的 base 状态。

### 3. 「喊」和「演」可以分开：看音量

- **干净表演**：C_normal + happy，F0 跨度 +50Hz、F0 中位 214→255、**音量只 +0.7dB**
- **靠音量顶**：C_soft + angry **+11.9dB**、E_begging + angry +7.4dB、C_soft + happy +7.3dB

判定器把「ΔdBFS > +6dB」直接标为`靠音量顶上去，不是表演`。
这一条拦掉了 4 个本来会被误判成「成功」的组合。

### 4. 主音色实测：Charles 和 Hooper 完全不是一回事

| 主音色 | 能用的标签 | 不能用的 |
|---|---|---|
| **C_normal（Charles）** | happy ✔ / angry ✔ | sad ✘ / calm ✘ / afraid ✘ |
| **E_calm（Hooper）** | afraid ✔ / angry ✔ | happy ✘ / sad ✘ / calm ✘ |

两个主音色的 base 都**明显偏平**：F0 跨度 C_normal 56Hz / E_calm 61Hz，
真人中性是 138Hz。这是「语调没起伏」，不是模型判错（物理量独立佐证）。

而且 E_calm 打标签会**过冲 5 倍**：+happy 是 +5.61σ（真人的「开心」只要 +1.18σ）。
⇒ **E_calm 上不该打标签，它 base 的 −3.91σ 本身就已经是「冷」了。**

### 5. 意外发现：E_scold 才是最好用的情绪载体（4/5）

| ref | pass | 明细 |
|---|---|---|
| **E_scold** | **4/5** | happy ✔ sad ✔ calm ✔ angry ✔ afraid ✘ |
| C_normal | 2/5 | happy ✔ angry ✔ |
| E_calm | 2/5 | afraid ✔ angry ✔ |
| E_begging | 1/5 | happy ✔ |
| C_angry / C_excited / C_soft / E_loud | 0/5 | 全部失败 |

E_scold 的 base 在 −0.12σ（几乎正中中性），所以标签有双向余量：
5 个标签的 F0 跨度排序是 calm 64 < sad 75 < happy 109 < angry 126 < afraid 136，
**完全符合情绪语义**（Spearman ρ=0.79）。

## 三、方法学：三个不能省的对照

### 1. 同 seed 是可复现的，跨 seed 有噪声但不大

- 同 seed 2051 跑 3 次：**md5 完全一致**，A/V/D 差 0.0000
- 跨 seed（2052/2053/2054）：A 的 SD = 0.011（0.15σ），极差 0.025（0.34σ）

⇒ 配对比较的信噪比 ≈ 12 倍，**单条差值可信**。判据线定在 0.5σ（>3 倍噪声）是稳的。

**但 F0 跨度不是**：C_normal 的 base 在 4 个 seed 上是 56 / 55 / 69 / 98Hz，
近 2 倍差距。所以判定器**优先判 Δspan，绝对区间只作兜底**。

### 2. 参数变了结果就变，不是「只改上限」

`max_tokens` 从 240 改到 280，同 seed 同文本，**波形差到 0.83（峰值归一后）**，时长不变。
⇒ 任何跨批次比较必须参数逐项一致，不能假设「没触顶就没影响」。

### 3. e2v 在 TTS 输出上不可信，只能当佐证

48 条里 **30 条被判 angry**；sad 命中 0/8、afraid 命中 0/8、calm 1/8。
真人上它是好的（happy 召回 64%、laughing 92%、sad 70%），
⇒ 这是**域偏移**，不是模型不行。判定器里 e2v 不参与 pass/fail。

### 4. 顺手修掉的阈值口径错误

`emo_gate.py` 里 valence 的效应量分母写成 0.083，实际合并组内 SD 是 0.130
（真人口语 valence 的组内波动本来就大）⇒ 之前报告的 valence 效应量被**高估 1.57 倍**。
已改成 pooled within-group 值。

## 四、生产上怎么用（对白链路）

### 选 ref 的规则

```
目标 arousal 高（愤怒/激动/恐惧）→ 选 base 偏低的 ref：
    C_normal（主音色）/ E_calm / E_scold / E_begging，再打 happy|angry|afraid

目标 arousal 低（难过/平静）→ 不要打标签：
    用 base 本身就偏低的 ref（C_normal base 最像 sad：A=0.34、跨度 56Hz、e2v 判 sad 0.99）
    或用 E_scold + sad / + calm（唯一两个有效的低 arousal 组合）

base 已经很极端的 ref（C_excited / C_angry / E_loud）→ 不要打标签，直接用 base
```

### 判定器 `emo_check.py`

```bash
# 单条：有 base 时判得准
python emo_check.py --wav out/gen/C_normal__happy__s2051.wav \
                    --ref C_normal --emo happy \
                    --base out/gen/C_normal__base__s2051.wav --json

# 整批
python emo_check.py --dir out/gen --out out/gen_check.json
```

判据（全部来自本轮实测，有据可查）：

| 判据 | 阈值 | 依据 |
|---|---|---|
| Δ F0 跨度 | happy/angry/afraid ≥ +18Hz；sad/calm ≤ +25Hz | 同 seed 配对可消噪声 |
| Δ arousal 方向 | 符号必须与目标一致，且 ≥ 0.5σ | 0.5σ = 3.3 倍 seed 噪声 |
| Δ dBFS | ≤ +6dB | C_normal+happy 只 +0.7；C_soft+angry +11.9 就是喊 |
| 绝对 arousal 落点 | 各情绪区间（如 sad 0.20–0.48） | 防「从 0.80 退到 0.70 就叫 sad」 |
| A 上限 | 0.78 | 真人最高是 laughing 0.73 |

输出 `pass / warn / fail` + 逐条理由，可直接让上层决定「收 / 重生成 / 换 ref」。

## 五、局限（别当成已验证的）

1. **单句、单文本**（9 词一句话）。长句、多句、带停顿的对白没测，标签效应可能不同。
2. **一个 seed（2051）跑矩阵**。虽然配对安全，但「哪个 ref 天生适合哪个情绪」的
   绝对位置可能随 seed 漂 ±0.34σ。
3. **angry / afraid / calm 没有真人锚点**。Expresso 只有 default/happy/sad/confused/
   whisper/laughing/enunciated/emphasis 八种 style，所以这三个情绪的目标区间是
   「方向 + 参照相邻 style」构造的，不如 happy/sad 硬。
4. **valence 轴全程不可控**。所有标签的 ΔV 都在 ±0.5σ 内且方向不一致，
   真人 happy vs default 的 ΔV 也只有 0.15σ —— 这条轴在「中性→正向」上本来就没信号。
   要「开心」的 valence，只能靠 ref 本身 V 高，标签帮不上。
5. 补格 4 条（E_begging 的 sad/angry/afraid/calm）用的是 seed 2052，
   因为 2051 在它们上面系统性产出 0.32s 空音。组内 seed 不完全统一，已在 index 里标记。

# 附：评分引擎审计（2026-11-06 20:10）

## 一、当前实际在跑什么

| 通道 | 具体模型 | 规模/训练数据 | 输出 | 发布 |
|---|---|---|---|---|
| `vox_dim` | `tiantiaf/wavlm-large-msp-podcast-emotion-dim`<br>WavLM-large + LoRA(r16)，`use_conv_output=True` | MSP-Podcast（11.6 万段 / ~3000 说话人 / **自发播客口语**） | A / V / D 各 0–1 | 2025-05，Vox-Profile arXiv 2505.14648 |
| `e2v` | `iic/emotion2vec_plus_large` | 4.25 万小时微调，~300M 参数 | 9 类概率 | 2024-01 |
| `phys` | 无模型（Praat / parselmouth） | — | F0 中位/跨度、dBFS、HNR、浊音比 | — |

## 二、版本新旧：**两个神经网络引擎都是当前最新一批，没有更好的现成替代**

- **vox_dim 就是 INTERSPEECH 2025 SER Challenge Task 2 的冠军配方**（SAILER 系统，
  speech-only 变体，去掉文本模态以简化部署）。官方 model card 明确写了这一点。
  Task 2 榜首平均 CCC 0.6076，比 baseline 高 4.8%。
- **emotion2vec+ large 仍是开源权重的离散第一**。独立评测（oruk 2026-07，
  64,384 条统一七分类口径）：emotion2vec+ **68.7%**，Gemini 3 Flash 46.0%、
  GPT-Audio 1.5 43.3%、audEERING devAIce 42.2%。

⇒ **换引擎这个动作本身没有收益。** 问题不在新旧，在下文的三条域错配。

## 三、但「适合给有声书评分吗」——四条实测出来的硬限制

### 限制 1：输出区间被钉死在 [0.18, 0.82]

真人 745 条（Expresso 全量）实测：A 最小 0.18、最大 0.82，
**超过 0.85 的占 0.0%**。IS2025 挑战赛官方也记录了同一现象（"gravity of the mean"：
大多数段落聚在中性值，模型倾向于把极端值往均值拉）。

⇒ 上一轮用的「A > 0.82 = 吼叫区」**实际测的是模型的饱和上限，不是听感阈值**。
凡是贴着 0.18 / 0.82 的判据都要重写。

### 限制 2：3–15 秒是模型自己的可信区，我们的样本有一部分不合格

model card 原文：训练时过滤掉 `<3s`（判不准）和 `>15s`（算不动）的样本，
"you need to prepare your audio to a maximum of 15 seconds"。

- 生成集 48 条：**15 条 < 3s**（2.40–2.72s）⇒ 落在作者自己标注不可靠的区间
- 生产链 `merge_spans` 拼 3–15s 是对的方向，但本轮实验样本没做这个约束

### 限制 3：8 档参考里有 2 档超出模型见过的范围

| ref | A | 状态 |
|---|---|---|
| C_excited | **0.87** | 超出真人语料上限 0.82（外推） |
| E_loud | **0.85** | 同上 |
| 其余 6 档 | 0.26–0.78 | 区间内 |

8 档 A 的 SD = **0.244**，是真人说话人内 SD（**0.132**）的 1.8 倍 ——
我们故意挑的都是戏剧化极端切片，本身就不是 MSP-Podcast 的自然分布。
48 条生成物里也有 6 条 A > 0.82（外推）。

⇒ **这解释了 V 为什么全塌在 0.43 以下**：参考系就在分布外，
回归器按训练分布往回拉是必然的，不能全记在生成侧账上。

### 限制 4：emotion2vec 在这里已饱和，不能当分类器用

- 48 条生成物里 **23 条输出恰好 p = 1.000**，置信度中位 1.000
- **30/48 判 angry**（真人 Expresso 也是 59% > 0.99）
- 9 类离散没有「平静叙述 + 细微起伏」这一档，而有声书 90% 是这一类

⇒ 一个对 30/48 条都喊「100% 愤怒」的模型，置信度轴等于不存在。
只能当极粗的「有没有跑飞」哨兵，不能进判定。

### 附加：语义错配（不是声学错配）

podcast SER 量的是「说话人自己什么感受」，有声书要的是「叙述者把角色演成什么样」。
**Dominance 尤其错位**：演一个怯懦角色 ≠ 叙述者本人弱势。
而且有声书的强度是**相对相邻句**的，SER 逐条孤立打分没有上下文。

## 四、结论：换什么、不换什么

| 项目 | 决定 | 理由 |
|---|---|---|
| vox_dim | **不换** | 已是挑战赛冠军配方，换任何现成开源模型只会更差 |
| vox_dim 的 A/D | **只用相对量（Δ 对同 ref base）** | 绝对值受域偏移污染；相对量配对能消掉 |
| vox_dim 的 V | **弃用** | 生成侧上限 0.43 < 真人中性 0.54，且本轮全部 ±0.5σ 内无方向 |
| emotion2vec | **降为弱哨兵或停用** | p=1.000 饱和 + 9 类离散与有声书不匹配 |
| phys | **保留并提高权重** | 唯一完全不受训练域影响的轴 |
| ref 选材 | **必须落在分布内** | C_excited / E_loud 两档要标注「外推」，别拿来当靶心 |

**引擎不旧、不用换。错的是「拿它当唯一裁判」和「拿戏剧化切片当参考系」。**

## 五、给有声书打分真正缺的三件（不是模型，是方法）

1. **书内相对归一**：同一本书 / 同一角色的 z-score，而不是跨库绝对分。
   有声书的表达力是「这一句相对上一句」，不是「这一句在世界范围内多激动」。
2. **长音频聚合**：现有链 3–15s 分段打分后要按书聚合，看整章的动态范围，
   而不是逐句判定（逐句判定已经在限制 4 上失效）。
3. **参考式韵律评测**：TTSDS2 PROSODY（MPM 轮廓 / Pitch 分布 / HuBERT 节奏 /
   Allosaurus 语速）才是为 TTS 设计的评测口径，我们本地已有 `_proso_batch.py`；
   加上 `_align_lib.py` 的 `rel_z` 做句内重音。**SER 只该是第三层兜底。**

# 附：书级评分在真实成品上的验证（2026-11-06 20:40）

上一节说「真正缺的三件是方法」，这一节把第 1 件（书内相对归一）**直接拿生产成品做掉**，
用的是已交付的 60 条真实对白（`G:/_setup/ch123_final`，E 36 条 / C 24 条，
带说话人与预期情绪标签 `_ch123_check.json`）。脚本：`book_judge.py` + `book_analyze.py`。

## 一、先纠正一个方法论：书内 z 归一**不可能**改善排序类指标

我原本以为「书内归一能提高情绪区分力」。**这是错的，而且是数学层面的错**：

- AUC 只看名次；
- `z = (x−μ)/σ` 是单调变换，名次不变；
- ⇒ 全书 z 的 AUC 与 raw **逐位相同**（实测核对：0.6952 vs 0.6952）。

书内归一的真实价值只有两个：**可读性**（把 0.32 说成「比本书中位低 1.2σ」）
和**跨书可比**（不同书的 0.4 含义不同）。想改区分力只能改**分组方式**。

## 二、按角色归一反而让区分力变差

预期 sad(11) vs calm(34)，AUC：

| 组合 | raw（绝对） | char（按角色 z） | 变化 |
|---|---|---|---|
| A | **0.695** | 0.583 | −0.112 |
| F0 跨度 | 0.717 | 0.695 | −0.021 |
| D | 0.612 | 0.572 | −0.040 |
| A+跨度 | **0.759** | 0.703 | −0.056 |
| A+0.5·跨度 | **0.765** | 0.684 | −0.080 |

按角色去均值相当于把「C 整体比 E 重」这件**真事**当噪声除掉——
而这条恰恰承载了一部分区分信息。⇒ **正确做法：按角色分组看趋势，但不要跨组做归一。**

同角色相邻句也验证了同一点：`Δ(A−μ_w) ≡ ΔA`，去角色均值只改除数、不改差值，
所以「按角色归一后起伏变大」是错觉（第一版报的 `0.07σ vs 0.73σ` 是单位混用，已作废）。

## 三、真正的结论：这本书的动态范围只有真人的 3–5 成

这一条不依赖情绪分类对不对，用物理量+维度直接算：

| | A p10–p90 范围 | 真人对照 | F0 跨度 p10–p90 | 真人对照 |
|---|---|---|---|---|
| 角色 C（23 条） | 0.27–0.41 = **0.13** | **36%** | 29–109 Hz | 56% |
| 角色 E（36 条） | 0.19–0.39 = **0.20** | **55%** | 35–115 Hz | 56% |
| 真人 745 条 | 0.30–0.67 = 0.37 | 100% | 65–208 Hz | 100% |

但**句间对比是够的**：同角色相邻句 |ΔA| 中位 **0.75σ**、p90 2.35σ，只有 18% ≤0.3σ。

把两条放在一起才是准确描述：
**局部有起伏（每句在动），全局没跨度（整章一个调）。**
这正是「念得平但不算机械」的听感来源——不是没有变化，是变化被压在一个窄带里来回抖。

## 四、模型本身没问题，是成品里真的没那么多差别

同一模型在 Expresso 真人表演上：**happy vs sad 的 A AUC = 0.991**（90/94 条），
laughing vs sad = 1.000。而在我们这本书内只有 0.70–0.77。

⇒ **不是 SER 在这个任务上失效，是成品确实比真人表演平。** 这条比上一节的「域错配」更要紧：
域错配影响的是绝对值的可信度，而动态范围是**相对量**，不受域偏移影响。

## 五、三条会让书级结论失真的坑（已在脚本里处理）

1. **56% 的句子 <3s**（33/59，中位时长 2.72s）——模型训练时滤掉 <3s，作者自标不可靠。
2. **A 全落在 [0.11, 0.57]**，而模型输出上限 0.82 ⇒ 整本书都在中性偏下，
   **根本够不到天花板**，所以书级只能判「够不够起伏」，**判不了「有没有演过头」**。
3. **生产链 −24dBFS 归一后 speech_db 只剩 3.2dB 跨度** ⇒ 音量轴已不可用，
   「ΔdB ≤ 6 就说明在演不是喊」这条判据**在成品上失效**，只能用在生成原始输出上。

## 六、结论

| 问题 | 答案 |
|---|---|
| 书内归一能不能提高区分力 | **不能**（数学不允许），只能提高可读性与跨书可比 |
| 按角色归一行不行 | **不行**，区分力从 0.695 掉到 0.583 |
| SER 能给有声书打分吗 | **能打「动态范围」和「句间对比」，不能打「情绪对不对」** |
| 这本书现在什么水平 | 动态范围 ≈ 真人的 3–5 成；句间对比正常 |

**给这条线的最终口径：书级只报三个数——动态范围（对真人百分比）、句间对比（σ）、
低于 3s 的占比（可信度）。不报逐句情绪标签，那个在书内本来就没有信号。**

同音色、同文本、只换情绪标签的 48 对（高激活 angry/afraid/happy vs 低激活 sad/calm）：

| 指标 | 排序正确率 | 95% CI | 二项检验 p |
|---|---|---|---|

## 三、业界现成的「情绪到位度」标准（调研结论）

| 方案 | 与人耳一致性 | 是否可零训练使用 | 结论 |
|---|---|---|---|
| **SES-Judge**（arXiv 2609.32504，NTU） | Spearman **0.5297** | 权重未发布 | 目前公开最高 |
| SES 的 VAD 余弦基线（同论文） | Spearman 0.4820 | ✔ 可复现 | 零训练最佳近似 |
| **EAS 情绪符合度**（IEEE Access 2026） | 与人类评分「中度正相关」 | 需学原型 | 无 GT 场景最合适 |
| Emo-SIM（emotion2vec 余弦） | 论文明确「与人耳选择不一致」 | ✔ | **不可靠** |
| 离散分类准确率 | — | ✔ | **口径本身就不对** |

**关键认知修正**：人耳问的是「这段离目标情绪有多近」（连续量），不是「这属于哪一类」。
用分类准确率评价情绪表现，口径从根上就错了——这也是之前 22% 那个数看着难看的原因。

## 四、诊断：不是判不准，是真的没演出来

59 条成品的声学实测（按生产时的情绪标注分组）：

| 标注 | n | A | D | V | F0 跨度 | 时长 |
|---|---|---|---|---|---|---|
| calm | 34 | 0.32 | 0.40 | 0.32 | 48 Hz | 2.27 s |
| sad | 11 | 0.36 | 0.42 | 0.36 | 84 Hz | 3.68 s |
| **happy** | 7 | **0.22** | **0.32** | **0.24** | 63 Hz | 3.27 s |

**标了 happy 的句子，arousal 0.22 比标 calm 的 0.32 还低，V 0.24 也比 calm 的 0.32 低。**
真人 happy 的 A 是 0.59（p25–p90 = 0.52–0.69）——差 **5 个标准差**。

⇒ 这不可能是测量误差：任何听者都会觉得这 7 条比「平静」的句子更低沉。
⇒ **happy 这一档从来没有被演出来过**，模型判 0/5 是正确判断，不是模型失效。

sad vs calm 则是另一回事：A 只差 0.05、跨度差 36 Hz，而真人这两类本来也只差 0.04
⇒ **这两个情绪在声学上天然接近，分不开是任务难度，不是缺陷**。

## 五、结论

1. **想要的「判得准」在离散情绪上不成立**：11 个配置里 8 个不高于瞎猜，2 个显著低于瞎猜。
2. **成立的只有一个**：同音色内「这句比那句强多少」，A 排序 81.2%、ρ=0.70，显著。
3. **业界有标准，但没有一个是「分类」**：最接近人耳的是 SES 的参考式相似度（0.53），
   其次是无 GT 的 EAS 符合度；Emo-SIM 与分类都被论文点名不可靠。
4. **我们的实际问题不是测量**：happy 档声学上比 calm 还低 5σ，是生成/标注没做到位。
   先修这个，比换任何评分引擎都有用。
