# 八档音色实测报告：非主音色到底能不能用（2026-11-06）

主音色（C_normal / E_calm）之外还有六档：C_soft / C_excited / C_angry / E_loud / E_scold / E_begging。
这份报告回答三件事：**它们各自能不能用、怎么用、以及为什么有些怎么打标签都没用**。

数据来源：同一句 9 词文本，8 音色 × 6 条件（base + 5 标签）= 48 条，seed 2051。
三通道打分（Vox 维度 / emotion2vec / Praat 物理量），判定见 `emo_check.py`。

---

## 零、先修掉的两个测量错

### 1. HNR 口径错误（影响所有「气声」判断）

`ser.phys` 原来对**整条音频**的 harmonicity 取中位数，而 Praat 对无周期帧返回 `-200` 哨兵值。
只要静音帧过半，中位数整块塌成 `-200` ⇒ **这个指标量的其实是「静音占比」**。

- 48 条里 **10 条**被误判为 `-200`
- 典型：C_normal base 2.9dB，同一个 ref 的 sad 却是 -200（不可能差这么多）
- 修正后（只取浊音帧、剔哨兵）：生成侧中位 **13.8dB**、最低 9.9dB

**连真人锚点也是错的**：旧口径下真人中性 HNR = 6.2dB，实际是 **13.5dB**（真耳语 5.3dB）。
判定器阈值 1.0dB 因此等于永不触发，已改为 9.5dB。

> 上一轮结论里「E_scold+happy HNR −1.3 偏低」「C_angry+happy HNR 0.9 发虚」两条**作废**，
> 修正后分别是 10.7 / 11.1dB，都正常。

### 2. 「happy 做不出来」的说法过头了

按最近落点归类 48 条时 happy 命中 0 条，但那是 V 轴权重造成的：
**去掉 V 权重后 happy 命中 5 条**，最佳候选 `E_scold+angry` 跨度 126Hz（目标 153）、A 0.58（目标 0.59），
只有 V 差 0.34。

⇒ 真实结论是：**跨度和强度都做得到，只有 V（正负）做不到**。见第三节。

## 一、核心机制：换音色换的是「音区 + 强度」，不是「起伏」

拿 8 档 ref 本身（真人录音）过同一套模型，再对比它们生成的 base：

| ref | 参考（真人切片） | 生成 base | 变化 |
|---|---|---|---|
| | A / 跨度 / F0 | A / 跨度 / F0 | ΔA / Δ跨度 |
| C_normal | 0.54 / 104 / 252 | 0.34 / 56 / 214 | −0.19 / **−48** |
| C_soft | 0.26 / 59 / 184 | 0.11 / 112 / 169 | −0.16 / **+54** |
| C_excited | 0.87 / 121 / 362 | 0.90 / 205 / 347 | +0.03 / +84 |
| C_angry | 0.78 / 229 / 407 | 0.80 / 107 / 338 | +0.02 / **−122** |
| E_calm | 0.31 / 147 / 204 | 0.24 / 61 / 193 | −0.07 / **−86** |
| E_loud | 0.85 / 115 / 334 | 0.79 / 136 / 380 | −0.06 / +21 |
| E_scold | 0.47 / 60 / 219 | 0.51 / 77 / 259 | +0.04 / +17 |
| E_begging | 0.78 / 264 / 263 | 0.49 / 38 / 209 | **−0.29 / −226** |

三条相关系数（排除 E_begging，它的 ref 是 9.5s 长句、跨 264Hz，与另七档不同质）：

```
arousal   r = +0.96   斜率 1.18   ← 强度被完整继承，甚至略微放大
F0 中位    r = +0.87   斜率 0.87   ← 音区被继承
F0 跨度    r = +0.06   斜率 0.05   ← 完全没继承
```

**这就是全部问题的根源：模型复制了 ref 的音高位置和响度，但完全不复制它的语调起伏幅度。**

- 你换音色，换到的是「这个人说话在哪个音区、有多用力」
- 你换不到「这个人说话起伏有多大」——那是模型按自己的习惯生成的
- 所以 E_begging 那个 264Hz 的大起伏哀求腔，生成出来只剩 38Hz（八档最平），
  哀求感几乎全靠文本撑
- 反过来 C_soft 的平坦参考（59Hz）被拉成 112Hz，比参考还颠

**变差分解也支持这一点**：跨音色的 SD 是音色内（标签）SD 的 **2.9 倍**（arousal 0.288 vs 0.101）、
**1.5 倍**（F0 跨度 53.9 vs 37.1）。

⇒ 想要情绪跨度，**优先换音色；标签只能在同一个音色内部微调**。这跟「主音色最常用」不矛盾——
主音色承担中性线，情绪档位本来就应该交给其他音色。

### Charles（Kingshaw）四档排班

| 档位 | 干什么 | 别干什么 |
|---|---|---|
| **C_normal** | 日常对白；要轻微正向就 `+happy`（跨度 56→106、音量只 +0.7dB，最干净的一组）；要发火就 `+angry`（→185Hz） | `+sad` / `+calm`（方向反，A 反而升） |
| **C_soft** | 低语、犹豫、不想被听见。**裸用**，A=0.11 已经够低 | 任何标签都不行：+happy/+angry 只涨 7.3/11.9dB 音量、跨度不动甚至缩 → 是「放大声」不是「演」 |
| **C_angry** | base 就是吼。唯一有价值的用法是 `+happy`：A 0.80→0.66、V 0.23→0.43、e2v 判 happy ⇒ **「怒气收回、带点笑」这个中间态**。它的 V=0.43 是全矩阵最高、e2v 也判 happy，

| **C_excited** | 只当「失控 / 尖叫」的一次性事件 | 指望它演任何情绪：跨度 205 已超 happy 上限 190，五个标签全把它收窄 9–100Hz |

### Hooper（Edmund）四档排班

| 档位 | 干什么 | 别干什么 |
|---|---|---|
| **E_calm** | 冷场、轻蔑、不接话。base 的 A=0.24 本身就是「冷」 | `+happy`：A 抬 5.61σ（真人只要 1.18σ），过冲 5 倍；`+sad`/`+calm` 方向反 |
| **E_scold** | **所有中间强度的活都给它**：训斥、得意、压人一头。sad / calm / happy / angry 全过，跨度排序 calm 64 < sad 75 < happy 109 < angry 126 完全符合语义（ρ=0.79） | `+afraid`（A 0.62 卡在上限，跨度 136 仍属激动区） |
| **E_loud** | 爆发单句。base A=0.79、F0 380 全场最高 | 任何标签：跨度从 136 被压到 39–127，A 全部下降——只会把它变弱，不会变成别的情绪 |
| **E_begging** | 哀求、认输。**裸用**，靠文本和停顿 | `+sad`/`+calm`/`+afraid`/`+angry`：跨度从 38 爆到 110–196（过冲 4–5 倍），A 冲到 0.78–0.82 直接进吼叫区；只有 `+happy` 可用（→87Hz、A 0.67） |

## 三、五个情绪里，只有三个在声学上是分开的

按最近落点归类 48 个候选（V 权重归零，避免 V 轴掩盖）：

```
angry 22   sad 10   afraid 6   calm 5   happy 5
```

但「最佳候选重合度」暴露出真正的问题：

| 组合 | 前 5 候选重合 | 含义 |
|---|---|---|
| happy vs **afraid** | **4/5** | 声学上同一档 |
| sad vs **calm** | **3/5** | 声学上同一档 |
| 其余八对 | 0/5 | 可分开 |

**原因在 V 轴**：

- 生成侧 V 的范围是 **0.15–0.43**（中位 0.23）
- 8 档真人 ref 的 V 是 **0.21–0.51**
- 真人语料 happy 的 V 中位是 **0.56**，default 0.54

模型在真人 ref 上测 V 是准的（0.21–0.51，与语料同区间）⇒ **评价头没偏，是生成侧真的把 V 压低了约 0.05–0.1，
而且压完的天花板 0.43 低于 happy 需要的 0.56**。

happy 与 afraid 的区别本来就在 V（0.56 vs 0.28），V 做不到 ⇒ 两者塌成同一档。
sad 与 calm 的区别也在 V（0.40 vs 0.48）⇒ 同样塌。

**生产含义**：

1. 「开心」和「害怕」不要指望靠声学参数分开——靠文本内容、停顿、语速去区分
2. 「难过」和「平静」同理，用同一个档位就够
3. 想要真正正向的 happy，前提是**先有一个 V 高的 ref**。本轮八档里 V 最高的是 E_scold 0.51 和 C_normal 0.50，
   都不够；这两档也正是全矩阵里 happy 成绩最好的两档（与机制一致）

## 四、打标签的可用性，由 ref 的 base 位置决定

把 40 个「音色 × 标签」配对按 ref 的 base 强度排开，规律非常整齐：

| base A 区间 | 打标签的后果 | 本轮成员 |
|---|---|---|
| **< 0.30（低区）** | 一律往上顶 +1.4 ~ +7.0σ，且**跨度不涨、只涨音量**（+5 ~ +12dB）⇒ 是喊不是演 | C_soft 0.11 / E_calm 0.24 |
| **0.45 ~ 0.58（中区）** | 双向都有余量，方向可控 | **E_scold 0.51** / E_begging 0.49（但它跨度只有 38，一碰就爆） |
| **> 0.75（高区）** | 一律往回收 −0.4 ~ −2.0σ，跨度普遍收窄 ⇒ 只能当「降档旋钮」，降完不等于目标情绪 | C_angry 0.80 / E_loud 0.79 / C_excited 0.90 |

`r(base_A, ΔA) = −0.64`，斜率 −0.39。这就是「标签只能往回收」「越偏的 ref 越救不回来」的定量版本。

**唯一落在中区的 E_scold 是 4/5 通过的原因**，不是它特别强，是它的 base 恰好没偏。

## 五、结论：非主音色的正确用法

1. **六档全部可用，但用法是「裸用 base 当情绪档位」，不是「给它们打标签」。**
   八档 base 的 A 覆盖 0.11–0.90（真人全集 0.10–0.92 的绝大部分），这一轴由选音色解决。

2. **打标签只对 E_scold 划算（4/5）**，其余五档加起来只多出 5 个可用组合
   （C_normal happy/angry、E_calm afraid/angry、E_begging happy）。

3. **换音色换不来起伏。** 模型不继承 ref 的 F0 跨度（r=0.06），
   E_begging 的 264Hz 哀求腔被压成 38Hz、C_angry 的 229Hz 被砍到 107Hz。
   要起伏只能靠标签，而标签方向不可控 ⇒ **起伏这一轴目前没有可靠手段**。

4. **V 轴是结构性缺口。** 生成上限 0.43 < happy 需要的 0.56，
   导致 happy≈afraid、sad≈calm 两对在声学上不可分。正向情绪要另找 V 高的 ref，本轮八档都不够。

5. **音量是「喊」和「演」的分界线**（沿用上一轮）：干净表演几乎不动音量（+0.7dB），
   超过 +6dB 的一律降级——这条拦掉了 C_soft+angry（+11.9dB）、E_begging+angry（+7.4dB）等。

# 附：表现力评分（2026-11-06 20:xx，第二问）

上一份回答的是「打什么标签」，这一问是「**这一档本身演某种情绪能打几分**」。
两套判据回答不同问题，必须分开看：

| 判据 | 问题 | 工具 |
|---|---|---|
| 相对判定 | 打了标签，相对自己的 base 变了没有 | `emo_check.py` |
| **绝对评分** | 这段音频落在真人该情绪的落点区间里吗 | `expressiveness.py` |

**为什么之前没有这个数**：`gen_check.json` 里 8 条 base 的 `emo` 是 `None`，
它们从来没对着任何情绪目标判过 ⇒ 只能回答「标签有没有用」，回答不了「这一档行不行」。

## 评分口径（含一次自我推翻）

```
真人区间 [p25, p90]：laughing 跨度 108–209 / A 0.65–0.76 / D 0.61–0.72
                     happy    跨度 123–229 / A 0.52–0.69 / D 0.57–0.69
                     sad      跨度  60–149 / A 0.29–0.40 / D 0.36–0.48
dev_x = 0（区间内）否则 越界距离 / 尺度（跨度用对数 0.30；A 0.0729；D 0.10）
fit   = 2·dev_span + dev_A + 0.3·dev_D
score = 100·exp(−fit/3)      锚：0→100  1→72  2→51  3→37  4→26
```

**第一版用的是单点中位数当靶心，那是错的**：真人 laughing 的 A 中位是 0.68，
但 p90 就有 0.76、最高 0.82。拿 0.68 当靶心，真人自己演得激动一点就会被判「过冲」——
实测把 C_excited 这一档的**真人参考切片**喂进去只有 18 分。
改成区间后同一段是 54 分。**靶心 vs 区间，差的不只是宽容度，是会给出反向结论。**

## 结果四：真正能用的组合只有 9 个

评分 ≥60 **还不够**。`E_begging+angry` 在「愤怒」上拿 100 分，但它同时 +7.4dB、
A 冲到 0.82——那是喊不是演。必须叠加音量判据（ΔdB ≤ 6，A ≤ 0.82）：

| 情绪 | 可用组合（分数 / 条件） |
|---|---|
| **激动** | **E_loud 85**（裸用）、**C_angry 72**（裸用）、E_scold+happy 65、E_begging+happy 61 |
| **开心** | **E_scold+happy 77** |
| **难过** | C_soft+sad 100、E_scold+sad 93、C_normal+sad 87、E_calm 76（裸用） |

注意三件事：

1. **C_normal 和 E_calm 这两个主音色，在「激动」「开心」上全被刷掉**（最高 53 / 37）。
   主音色只在中性与低落这一侧成立。
2. **C_excited 三个情绪一个都过不了**（49 / 34 / 5）。
   它 A 0.90 超过区间上限 0.76 达 1.9σ，**不是不够激动，是激动过头**。
3. 激动戏真正该由 **E_loud（Hooper）和 C_angry（Charles）** 承担，不是那两档名字里带 excited/angry 之外的其他档。

## 必须说清的三条局限

1. **真人参考切片在这把尺子上也只有 51–71 分**（激动列）。因为它们是戏剧化切片，
   常顶到区间边缘（C_angry 的参考跨度 229Hz，超过 p90 的 209）。
   ⇒ 分数是「与真人典型区间的吻合度」，不是绝对表演力；跨音色比较有效，绝对值别当等级。
2. **愤怒 / 害怕 / 平静三列（带 \*）没有真人分布**，按语音学构造。正控里中性 ref 在「害怕」上拿 100、
   在「平静」上拿 99 ⇒ **这三列区分度弱，只看相对排序，别信绝对值**。
   根因还是 V 不可用：害怕与「情绪饱满的中性」在 A/跨度/D 上同形。
3. 「平静」被「念得平」通吃：任何窄跨度低 A 的输出都能拿高分，包括那个听感发闷的 C_normal base。

## 一句话总结

**表现力的差别主要是一条 arousal 滑梯，不是「谁更会演」。**
E_loud 在激动侧 85 分、C_normal 在难过侧 86 分，各自把一头做到接近真人；
但没有任何一档能跨两头，也没有一档能在 V 轴上做出正向情绪。
标签的作用是**给低档补强度**（C_normal+angry 3→100），对高档只减分（E_loud 激动 85→52）。
